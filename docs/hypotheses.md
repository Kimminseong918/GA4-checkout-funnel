# 가설 정리

## 판정 원칙
- 판정 기준과 가설별 행동은 결과를 보기 전에 정한다
- 비율 차이는 **p < 0.05**와 **상대 차이 10% 이상**을 모두 만족해야 "차이가 있다"고 판정한다
  - p < 0.05: 차이가 우연이 아닌지
  - 상대 차이 10% 이상: 화면이나 정책을 바꿀 만큼 의미 있는 크기인지 (세션이 10만 개 이상이라 작은 차이도 유의하게 나오기 때문)
- 기각된 가설도 지우지 않고 기록한다
- 검정 코드: `notebooks/p1_stat_tests.ipynb`

| H6 | 개선안 할인 기간 적용 | 쿠폰 적용 화면 개선 등 다음 후보 시험 | 실험 설계 단계 |

## H1. 시즌 방문자의 세션 전환율은 비시즌보다 낮다 ❌

| 항목 | 내용 |
|---|---|
| 배경 | 현업 요청 "방문이 늘었으니 성과가 좋았죠?"에 숨은 가정(방문 증가 = 성과)을 검증 |
| 근거 | 시즌에는 가격만 확인하는 등 구매 의도가 낮은 방문이 섞여 전환율이 희석될 수 있음 |
| 지표 / 비교 | 세션 전환율, 시즌(11/23~12/18) vs 비시즌(1/5~1/31) |
| 결과 | 시즌 1.91% vs 비시즌 0.99%. 하루 세션 +20%, 하루 구매 세션 2.3배 |
| 판정 | 기각. 시즌 전체로는 희석보다 구매 증가가 훨씬 큼 |
| 다음 | 질문을 "비시즌 하락은 어디서, 누구에게서"로 재정의. (희석 아이디어는 이후 할인 기간 신규의 결제 단계에서 다시 나타남 → H4-b) |

## H2. 비시즌 전환율 하락은 장바구니 이후 단계에 집중된다 ❌

| 항목 | 내용 |
|---|---|
| 근거 | 구매 의도가 있는 사람이 결제 과정에서 빠지는 것이라면 개선 가능한 누수 |
| 지표 | 단계 전환율, 하락 기여도 (ln 분해) |
| 판정 기준 (사전) | 장바구니 이전 기여가 크면 계절 요인, 이후 기여가 크면 개선 가능한 누수 |
| 결과 | 하락 기여: 조회 20% / 구매 의도 67% / 결제 시작 32% / 결제 정보 −23% / 구매 4%. 장바구니 이전 합계 87% |
| 검정 | 앞쪽 3단계 모두 p < 0.0001, 결제 정보 → 구매는 p = 0.147로 차이 없음 |
| 판정 | 기각. 비시즌 하락은 결제 과정이 아니라 구매 의도 감소 |
| 참고 | 장바구니 이후 합계 13%는 결제 정보 단계의 상승(−23%)이 상쇄한 결과 |

## H2-s. 장바구니 없는 구매는 이전 세션에서 장바구니에 담았기 때문이다 ❌

| 항목 | 내용 |
|---|---|
| 배경 | 엄격 기준 퍼널에서 구매 세션의 30.7%(시즌) / 24.9%(비시즌)가 장바구니 기록 없이 구매 |
| 판정 기준 (사전) | 70% 이상이면 주된 원인 (대부분을 설명해야 주된 원인이라 할 수 있음) |
| 결과 | 시즌 15.8% / 비시즌 15.9%. 조회 기간을 11/1로 넓혀도 4건만 증가 |
| 판정 | 기각. 나머지는 바로 구매, 기기 변경, 기록 누락으로 추정 (구분 불가) |
| 다음 | 장바구니 단계를 "구매 의도"로 재정의, 최대 도달 기준 퍼널 채택 |

## H3. 비시즌 구매 의도 하락은 신규 방문에서 재방문보다 크다 ✅

| 항목 | 내용 |
|---|---|
| 근거 | 시즌에는 선물을 사러 처음 온 방문자가 많았고, 이들이 비시즌에 사라졌을 것 |
| 지표 | 조회 → 구매 의도 전환율의 시즌 대비 비시즌 변화 |
| 결과 | 신규 30.75% → 17.15% (−44%) / 재방문 42.15% → 34.99% (−17%) |
| 검정 | 로지스틱 회귀 기간 × 신규 상호작용: 계수 −0.460, 오즈비 0.631, p < 0.001 |
| 추가 결과 | 비시즌 하락의 약 86%는 그룹 내 변화, 약 14%는 재방문 비중 감소(29.3% → 24.4%) |
| 판정 | 지지. 비시즌 하락은 시즌에 왔던 신규가 빠진 계절 요인 |
| 발견 | 결제 시작 → 결제 정보: 재방문은 시즌·비시즌 81~83%로 안정, 시즌 신규만 44.8% (재방문 대비 −46%, p < 0.0001) |

## H4. 시즌 신규의 결제 이탈은 모바일·미국 외 국가에서 더 크다 ❌

| 항목 | 내용 |
|---|---|
| 근거 | 모바일은 입력이 불편하고, 해외는 배송비·배송 기간 부담이 큼 |
| 지표 | 시즌 신규의 결제 시작 → 결제 정보 전환율 |
| 결과 | 모바일 45.7% vs 데스크톱 44.4% / 미국 외 45.3% vs 미국 44.3% |
| 검정 | p = 0.50, 0.60. 신뢰구간이 0을 포함, 방향도 반대 |
| 판정 | 기각. 시즌 신규는 모든 기기·지역에서 43~47%, 비시즌 신규는 62~68% → 차이는 시즌 여부에서 생김 |
| 다음 | 시즌 특유 요인(도착일, 가격 비교)을 주별 패턴으로 확인 → H4-b |

## H4-b. 할인 기간 신규의 결제 이탈은 최종 금액 확인 후 이탈 때문이다 ✅

| 항목 | 내용 |
|---|---|
| 판정 기준 (사전) | 마감에 가까울수록 신규 전환율 하락 → 도착일 / 블프·사이버먼데이 주에 가장 낮음 → 가격 비교 |
| 결과 | 신규: 11/23 주 40.6%, 11/30 주 40.8%, 12/7 주 44.2%, 12/14 주 64.3% / 재방문 79~85% |
| 검정 | 신규 블프 주 vs 마감 직전 주 −37% (p < 0.0001), 재방문 −7% (p = 0.013, 크기 기준 미달) |
| 판정 | 지지. 도착일 후보 기각, 할인 기간 신규의 최종 금액 확인 후 이탈로 해석 |
| 참고 | 쿠폰 적용 실패, 예상보다 높은 총액도 같은 패턴 가능 → 공통점은 "결제 화면에서야 최종 금액을 안다" |
| 다음 | 개선 대상: 할인 기간(11/23~12/13) 신규의 결제 정보 단계 (41.9%). 개선안: 최종 금액 사전 표시 → H6 |

## H6. 결제 전에 최종 금액을 보여주면 할인 기간 신규의 구매 전환이 오른다 ⬜

| 항목 | 내용 |
|---|---|
| A안 / B안 | 기존 / 장바구니·상품 페이지에서 할인·배송비 반영 최종 금액 표시 |
| 대상 | 할인 기간 신규 중 장바구니(구매 의도) 도달자 (하루 약 223명) |
| 핵심 지표 | 구매 ÷ 장바구니 도달 (기준 15.1%) |
| 진단 지표 | 결제 정보 ÷ 결제 시작 (기준 41.9%) — 효과 위치 해석용, 성공 판단에 쓰지 않음 |
| 가드레일 | 주문당 객단가 (기준 66.44), 방문자당 매출 |
| 최소 검출 효과 | +3.0%p (상대 +20%), 할인 기간 21일, α 0.05, 검정력 0.8 |
| 핵심 지표를 바꾼 이유 | B안은 장바구니에서 개입해 결제를 시작하는 사람 자체를 바꿈 → "결제 정보 ÷ 결제 시작"은 구매가 늘지 않아도 오를 수 있음 |
