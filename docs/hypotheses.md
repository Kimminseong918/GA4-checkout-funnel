# 가설 정리

## 판정 원칙

- 판정 기준과 맞으면·틀리면 할 행동은 결과를 보기 전에 정함
- 비율 차이는 **p < 0.05**와 **상대 차이 10% 이상**을 모두 만족해야 "차이가 있다"고 판정
  - p < 0.05: 차이가 우연이 아닌지
  - 상대 차이 10% 이상: 화면이나 정책을 바꿀 만한 크기인지 (세션이 10만 개 이상이라 작은 차이도 유의하게 나오기 때문)
- 기각된 가설도 지우지 않고 기록
- 검정 코드: `notebooks/p1_stat_tests.ipynb`

## H1. 시즌 방문자의 세션 전환율은 비시즌보다 낮다 — 기각

| 항목 | 내용 |
|---|---|
| 배경 | 현업 요청 "방문이 늘었으니 성과가 좋았죠?"에 숨은 가정(방문 증가 = 성과)을 검증 |
| 근거 | 시즌에는 가격만 확인하는 방문이 섞여 전환율이 희석될 수 있음 |
| 지표 | 세션 전환율, 시즌(11/23~12/18) vs 비시즌(1/5~1/31) |
| 결과 | 시즌 1.91% vs 비시즌 0.99%. 하루 세션 +20%, 하루 구매 세션 2.3배 |
| 판정 | 기각. 시즌 전체로는 희석보다 구매 증가가 훨씬 큼 |
| 다음 | 질문을 "비시즌 하락은 어디서, 누구에게서"로 변경 |

## H2. 비시즌 전환율 하락은 장바구니 이후 단계에 집중된다 — 기각

| 항목 | 내용 |
|---|---|
| 근거 | 구매 의도가 있는 사람이 결제 과정에서 빠지는 것이라면 고칠 수 있는 누수 |
| 지표 | 단계 전환율, 하락 기여도 (로그 분해) |
| 판정 기준 | 결제 시작 이전 기여가 크면 계절 요인, 이후 기여가 크면 고칠 수 있는 누수 |
| 결과 | 방문 → 조회 20% / 조회 → 결제 시작 99% / 결제 시작 → 결제 정보 −23% / 결제 정보 → 구매 4% |
| 검정 | 결제 시작 이전 단계 모두 p < 0.0001, 결제 정보 → 구매는 p = 0.147로 차이 없음 |
| 판정 | 기각. 비시즌 하락은 결제 과정이 아니라 결제를 시작하기 전에 생김 |
| 참고 | 장바구니 기준으로 나누면 조회 → 구매 의도 67%, 구매 의도 → 결제 시작 32%. 장바구니 기록 상태가 기간마다 달라 이 배분은 다소 불확실 (data_quality_checks 7·11·18행) |

## H2-s. 장바구니 없는 구매는 이전 방문에서 장바구니에 담았기 때문이다 — 기각

| 항목 | 내용 |
|---|---|
| 배경 | 구매 세션의 25~31%에 장바구니 기록이 없음 (20번) |
| 지표 | 장바구니 없는 구매 중 같은 사용자의 이전 방문에 장바구니 기록이 있는 비율 |
| 판정 기준 | 70% 이상 설명하면 엄격 기준 퍼널 유지 |
| 결과 | 시즌 15.8%, 비시즌 15.9% |
| 판정 | 기각. 장바구니 단계를 "구매 의도(장바구니 또는 바로 결제)"로 재정의, 최대 도달 기준 채택 |
| 참고 | 시즌은 11월 장바구니 기록 공백 때문에 과소 추정 가능. 기록이 정상인 12월을 이전 방문으로 둔 비시즌도 15.9%라 결론 같음 |

## H3. 비시즌 구매 의도 하락은 신규에서 재방문보다 크다 — 지지

| 항목 | 내용 |
|---|---|
| 근거 | 시즌에는 선물 등 시즌 수요로 처음 온 방문자가 많고, 이들이 비시즌에 줄었을 것 |
| 지표 | 조회 → 구매 의도, 조회 → 결제 시작 (신규·재방문별) |
| 결과 | 조회 → 구매 의도: 신규 −44% vs 재방문 −17%. 조회 → 결제 시작(장바구니 무관): 신규 −58% vs 재방문 −28% |
| 검정 | 로지스틱 회귀 기간 × 신규 상호작용: 조회 → 구매 의도 오즈비 0.631, 조회 → 결제 시작 오즈비 0.577, 둘 다 p < 0.001 |
| 판정 | 지지. 비시즌 하락은 신규 방문의 구매 의도 감소 = 계절 수요(선물 구매 등)가 끝난 영향으로 추정 |
| 다음 | 1월 성과는 평소 기준선(세션 전환율 1.0~1.3%)으로 평가 제안. 분석 중 시즌 신규만 결제 정보 단계에서 크게 이탈하는 것을 발견 (44.8% vs 재방문 82.8%) → H4 |

## H4. 시즌 신규의 결제 단계 이탈은 모바일·미국 외에서 더 크다 — 기각

| 항목 | 내용 |
|---|---|
| 근거 | 모바일은 입력이 불편하고, 해외는 배송비·배송 기간 부담이 큼 |
| 지표 | 시즌 신규 결제 시작 → 결제 정보 전환율 |
| 결과 | 모바일 45.7% vs 데스크톱 44.4%, 미국 외 45.3% vs 미국 44.3%. 비시즌 신규는 모든 조합 62~68% |
| 판정 | 기각. 방향도 반대이고, 차이를 만드는 것은 시즌 여부 |
| 참고 | 기기 비교는 태블릿 제외(56세션), 국가 비교는 포함. 국가 값 없음 15세션은 모두 이탈·모두 전환을 가정해도 결론 같음 |
| 다음 | 시즌 안의 시기 요인을 주·일별로 확인 → H4-b |

## H4-b. 성수기 신규는 결제 화면에서만 보이는 정보를 확인하고 떠난다 — 부분 지지

| 항목 | 내용 |
|---|---|
| 처음 가설 | 할인 기간 신규가 할인가를 기대했다가 결제 화면의 최종 금액을 보고 떠난다 (도착일 걱정이 아니다) |
| 처음 판정 기준 | 블프 주에 가장 낮으면 가격, 마감에 가까울수록 낮으면 도착일 |
| 처음 결과 | 신규 결제 정보 전환율 블프 주 40.6% → 12/14 주 64.3% (35번) → "할인 후 회복, 도착일 기각"으로 해석 |
| 재검토 1 | 할인 근거 확인: 할인 프로모션 없음, 상품 가격 인하 없음, 쿠폰 기록 없음 (37번) → "할인 기간" 가정 폐기 |
| 재검토 2 | 12/14 이후 상승의 정체: 결제 정보까지 가는 신규는 하루 약 47명으로 같고, 결제를 시작하는 신규만 114 → 65명으로 감소 (39번) → 개선이 아니라 분모 감소. 도착일 기각 근거도 무효 |
| 최종 판정 | 부분 지지. 성수기(11/26~12/14) 신규는 결제를 시작한 뒤 58%가 결제 정보 전에 떠나고, 배송 마감 무렵(12/15)부터 이런 결제 시작이 사라짐. 결제 화면에서만 보이는 정보를 확인하러 들어왔다 떠나는 것으로 해석. 그 정보가 최종 금액인지 도착 예정일인지는 로그로 구분 불가 |
| 판정 기준의 문제 | 비율만으로 판정하도록 정해 분모 변화를 놓침. 비율이 바뀌면 분자와 분모를 나눠 확인해야 함 |
| 다음 | 개선 대상: 성수기 신규의 결제 정보 단계 (42.3%, 재방문 82.1%). 개선안: 장바구니에서 최종 금액(배송비 포함)과 도착 예정일 표시 → H6 |

## H6. 결제 전에 최종 금액과 도착 예정일을 보여주면 성수기 신규의 구매 전환이 오른다 — A/B 설계

| 항목 | 내용 |
|---|---|
| A안 / B안 | 기존 / 장바구니에서 최종 금액(배송비·세금 포함)과 도착 예정일 표시 |
| 대상 | 성수기(11/26~12/14) 신규 중 장바구니(구매 의도) 도달자, 하루 약 240명, 사용자 단위 50:50 |
| 핵심 지표 | 구매 ÷ 장바구니 도달 (기준 14.4%) |
| 진단 지표 | 결제 정보 ÷ 결제 시작 (기준 42.3%). 효과 위치 해석용, 성공 판단에 쓰지 않음 |
| 가드레일 | 주문당 객단가 (기준 65.76), 장바구니 도달자당 매출 |
| 최소 검출 효과 | +3.0%p (상대 +21%), 19일, α 0.05, 검정력 0.8 |
| 핵심 지표를 바꾼 이유 | 처음에는 결제 정보 ÷ 결제 시작을 썼으나, 개선안이 장바구니에서 작동하면 결제를 시작하는 사람이 바뀜. 39번에서 결제 시작이 줄자 이 비율이 구매 증가 없이 42% → 71%로 오른 것을 확인 |
