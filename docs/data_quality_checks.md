## 데이터 한계
- 익명화된 샘플 데이터로 주문 ID 등 일부 값이 가려져 있음
- user_pseudo_id는 쿠키 기준: 기기 변경, 쿠키 삭제 사용자는 다른 사용자(신규)로 집계됨
- 로그인 ID(user_id)가 없어 기기 간 행동을 연결할 수 없음
- 전년도 데이터가 없어 계절 요인을 직접 분리할 수 없음
- 시즌 전 기간은 add_to_cart 기록이 대부분 누락되어 단계별 기준선으로 쓸 수 없음
- 배송 정보 이벤트가 결제 시작과 동시에 기록되어, 결제 화면 안에서 어디서 이탈했는지(배송비 확인 전/후) 구분할 수 없음
- '(not set)' 주문 번호 때문에 매출은 MAX(하한)와 주문 단위(상한) 사이
