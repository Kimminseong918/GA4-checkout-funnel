## 데이터 한계
- 익명화된 샘플 데이터로 주문 번호 등 일부 값이 가려져 있음
- 사용자 ID(user_pseudo_id)는 쿠키 기준: 기기 변경, 쿠키 삭제 사용자는 다른 사용자(신규)로 집계됨
- 로그인 ID(user_id)가 없어 기기 간 행동을 연결할 수 없음
- 전년도 데이터가 없어 계절 요인을 직접 분리할 수 없음
- 시즌 전 기간은 장바구니 기록이 대부분 누락되어 단계별 비교 기준으로 쓸 수 없음
- 배송 정보 이벤트가 결제 시작과 동시에 기록되어, 결제 화면 안에서 어디서 이탈했는지(배송비 확인 전/후) 구분할 수 없음
- 주문 번호 없는 구매 때문에 실제 매출은 MAX(하한)와 SUM(상한) 사이이며, 주문 단위 합산은 그 사이의 추정값
- 회사 주문 데이터베이스가 없어 GA4 매출을 실제 결제 매출과 대조할 수 없음
